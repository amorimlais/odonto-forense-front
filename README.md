# 🦷 OdontoCrim — Plataforma de Gestão de Perícias Odonto-Legais

Projeto desenvolvido como **Projeto Integrador da faculdade**, com o objetivo de criar uma aplicação voltada à área de perícia odontológica criminal, auxiliando na organização e gestão de informações relacionadas a laudos periciais e processos de identificação odonto-legal.

## 🎯 Sobre o projeto

O OdontoCrim é uma proposta de plataforma digital desenvolvida para apoiar profissionais da área de odontologia legal na organização de informações e no gerenciamento de atividades periciais.

A aplicação foi idealizada para facilitar a gestão de laudos, centralizar informações e contribuir para a organização dos processos de identificação odontológica.

O projeto surgiu a partir de uma atividade acadêmica que envolveu levantamento de necessidades, planejamento da solução e desenvolvimento da interface da aplicação.

## 💻 Desenvolvimento

Minha participação no projeto foi voltada ao **desenvolvimento Front-end**, com foco na construção das interfaces da plataforma, organização dos elementos visuais e experiência de navegação.

O desenvolvimento buscou criar uma interface intuitiva, organizada e adequada ao contexto de utilização da aplicação.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

*As tecnologias podem ser complementadas conforme a implementação final do projeto.*

## ✨ Principais objetivos da aplicação

- Apoiar a gestão de laudos periciais.
- Organizar informações relacionadas à identificação odonto-legal.
- Facilitar a visualização e o gerenciamento de registros.
- Proporcionar uma interface intuitiva para os usuários.
- Digitalizar e centralizar informações relacionadas aos processos periciais.
